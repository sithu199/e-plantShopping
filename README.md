# e-plantShopping

## Project Description
e-plantShopping is a React-based e-commerce application designed for plant enthusiasts. This platform allows users to browse a wide variety of houseplants, view details about each plant, and conveniently add them to a shopping cart. The goal of this project is to provide a seamless and aesthetic shopping experience for green lovers.

## Features
- **Product Listing:** A diverse collection of indoor and outdoor plants.
- **Shopping Cart:** Easy management of selected plants with real-time price calculation.
- **Responsive Design:** Fully functional on both desktop and mobile devices using Bootstrap/CSS.
